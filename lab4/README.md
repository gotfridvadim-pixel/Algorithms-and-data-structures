## a. Хипуй!

В этой задаче вам необходимо организовать структуру данных Heap для хранения целых чисел, над которой определены следующие операции:

- `Insert(k)` — добавить в Heap число `k` (`1 ≤ k ≤ 1 000 000`);
- `Extract` — достать из Heap наибольшее число, удалив его при этом.

### Входные данные

В первой строке содержится количество команд `N` (`1 ≤ N ≤ 100 000`), далее следуют `N` команд, каждая в своей строке. Команда может иметь формат `0 <число>` или `1`, обозначающий соответственно операции `Insert(<число>)` и `Extract`.

Гарантируется, что при выполнении команды `Extract` в структуре находится по крайней мере один элемент.

### Выходные данные

Для каждой команды извлечения необходимо отдельной строкой вывести число, полученное при выполнении команды `Extract`.

### Пример

**Входные данные**

```text
2
0 10000
1
```

**Выходные данные**

```text
10000
```

## c. Пирамида (минимум)

Задача отличается от задачи «Пирамида (максимум)» исключительно тем, что надо извлекать не максимум, а минимум.

Напишите программу, которая будет обрабатывать последовательность запросов следующих видов:

- `CLEAR` — сделать пирамиду пустой (если в пирамиде уже были какие-то элементы, удалить все). Действие происходит только с данными в памяти, на экран ничего не выводится.
- `ADD n` — добавить в пирамиду число `n`. Действие происходит только с данными в памяти, на экран ничего не выводится.
- `EXTRACT` — вынуть из пирамиды минимальное значение. Следует изменить данные в памяти и вывести найденное минимальное значение или, если пирамида была пустой, слово `CANNOT`.

### Входные данные

Во входных данных записана произвольная последовательность запросов `CLEAR`, `ADD` и `EXTRACT` — каждый в отдельной строке, согласно описанному формату.

Суммарное количество всех запросов не превышает `200 000`.

### Выходные данные

Для каждого запроса типа `EXTRACT` выведите его результат в отдельной строке.

### Примечание

Пирамиду с максимумом в корне объявляют как:

```cpp
priority_queue<T> the_heap;
```

Пирамиду с минимумом в корне объявляют как:

```cpp
priority_queue<T, vector<T>, greater<T>> the_heap;
```

Второй параметр (`vector<T>`) задаёт тип контейнера, в котором будет храниться пирамида, а третий параметр задаёт операцию сравнения. Вместо `T` следует написать тип элементов, которые будут храниться в пирамиде.

### Пример

**Входные данные**

```text
ADD 192168812
ADD 125
ADD 321
EXTRACT
EXTRACT
CLEAR
ADD 7
ADD 555
EXTRACT
EXTRACT
EXTRACT
```

**Выходные данные**

```text
125
321
7
555
CANNOT
```

**Решение:** [c.cpp](./с/c.cpp)

## e. Коммерческий калькулятор

Фирма OISAC выпустила новую версию калькулятора. Этот калькулятор берёт с пользователя деньги за совершаемые арифметические операции. Стоимость каждой операции в долларах равна 5% от числа, которое является результатом операции.

На этом калькуляторе требуется вычислить сумму `N` натуральных чисел. От порядка сложения чисел зависит итоговая стоимость вычислений. Например, пусть нужно сложить числа 10, 11, 12 и 13. Если сначала сложить 10 и 11 (это обойдётся в 1,05), затем результат сложить с 12 (1,65), а потом с 13 (2,30), то всего потребуется заплатить 5,00. Если же отдельно сложить 10 и 11 (1,05), затем 12 и 13 (1,25), а после этого сложить два полученных числа (2,30), итоговая стоимость составит 4,60.

Напишите программу, которая определит минимальную стоимость вычисления суммы данных `N` чисел.

### Входные данные

Первая строка содержит число `N` (`2 ≤ N ≤ 10⁵`). Во второй строке заданы `N` натуральных чисел, каждое из которых не превосходит `10 000`.

### Выходные данные

Определите, сколько денег потребуется для нахождения суммы этих `N` чисел. Результат должен быть выведен с двумя знаками после десятичной точки.

### Примеры

**Входные данные**

```text
4
10 11 12 13
```

**Выходные данные**

```text
4.60
```

**Входные данные**

```text
2
1 1
```

**Выходные данные**

```text
0.10
```

**Решение:** [e.py](./e.py)

## f. Таможня

Идёт 2163 год. Мишу, который работает в отделении таможни при космодроме города Нью-Питер, вызвал в кабинет шеф.

Как оказалось, недавно Министерство Налогов и Сборов выделило отделению определённую сумму денег на установку новых аппаратов для автоматического досмотра грузов. Средства были выделены с таким расчётом, чтобы грузы находились на таможне ровно столько времени, сколько требуется непосредственно на их досмотр.

В руках шефа оказался список грузов, которые будут контролироваться Министерством. Для каждого груза известны время его прибытия и время, требуемое аппарату для обработки этого груза. Один аппарат не может обрабатывать два груза одновременно.

### Входные данные

В первой строке задано число `N` (`0 ≤ N ≤ 50 000`) — количество грузов. В следующих `N` строках находятся по два целых положительных числа: время прибытия соответствующего груза и время, требуемое для его обработки.

Выведите одно число — наименьшее количество аппаратов, которое необходимо установить.

```

**Входные данные**

13 4
15 1

```

**Выходные данные**

```text

```

## g. Вычислительная ихтиология

Игорь работает младшим лаборантом в НИИ ихтиологии. Ему вверены `N` аквариумов, стоящих в ряд, в каждом из которых живёт колония рыбок гуппи. Про каждую колонию заранее известна её численность.

В лабораторных условиях колония рыбок гуппи растёт по следующему правилу: достигнув популяции в `x` рыбок, колония живёт в течение `max(1000 - x, 1)` секунд, после чего на свет появляется новая рыбка. От начального момента времени до рождения первой рыбки колония размера `x` также ждёт `max(1000 - x, 1)` секунд.

Например, колония с начальным размером 996 будет размножаться следующим образом:

| Момент времени | Размер колонии | Время до очередной рыбки |
|---------------:|---------------:|-------------------------:|
| 0              | 996            | 4                        |
| 4              | 997            | 3                        |
| 7              | 998            | 2                        |
| 9              | 999            | 1                        |
| 10             | 1000           | 1                        |
| 11             | 1001           | 1                        |
| 12             | 1002           | 1                        |
| ...            | ...            | ...                      |

Появление на свет каждой новой рыбки Игорь должен фиксировать в специальном журнале. Запись делается мгновенно, но в момент рождения новой рыбки Игорь должен находиться рядом с соответствующим аквариумом.

На перемещение от одного аквариума к соседнему у Игоря уходит одна секунда. В начальный момент времени Игорь стоит около первого аквариума.

Вычислите, в течение какого наибольшего периода времени Игорь сможет добросовестно выполнять свою работу.

### Входные данные

В первой строке содержится целое число `N` — количество аквариумов с рыбками гуппи. Каждая из следующих `N` строк содержит одно целое число `xᵢ` — численность `i`-й колонии.

### Выходные данные

Выведите момент времени, когда родится первая рыбка гуппи, запись о рождении которой Игорь сделать не сможет.

### Примечание

В приведённом примере Игорь сначала ждёт у первого аквариума появления рыбки на 4-й секунде. После этого он бежит к третьему аквариуму (на это уходит 2 секунды) и успевает к рождению рыбки на 6-й секунде. Однако вернуться к первому аквариуму, где следующая рыбка родится на 7-й секунде, он уже не успевает.

### Пример

**Входные данные**

```text
3
996
1
994
```

**Выходные данные**

```text
7
```

**Решение:** [g.py](./g.py)
