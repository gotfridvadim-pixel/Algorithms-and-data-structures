    Как это работает

    Хеш-функция складывает коды символов ключа. Остаток от деления суммы на число корзин задаёт индекс. У слов «кот» и «ток» одинаковая сумма, поэтому обе пары попадают в одну цепочку. При поиске Python проверяет её узлы по очереди.

    При вставке нового ключа в таблицу с загрузкой 100 % число корзин удваивается. Python заново распределяет пары по индексам. Повторная вставка существующего ключа обновляет его значение.
