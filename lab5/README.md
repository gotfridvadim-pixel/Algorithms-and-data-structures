# Лабораторная работа № 5

## a. Бинарное дерево (вставка, поиск, удаление)

Реализуйте бинарное дерево поиска, поддерживающее следующие запросы:

- `ADD n` — добавить число `n`, если его ещё нет в дереве. Вывести `DONE` при успешном добавлении и `ALREADY`, если число уже существует.
- `DELETE n` — удалить число `n`. Вывести `DONE`, если число было найдено, и `CANNOT` в противном случае. Вершину с двумя детьми необходимо заменить максимальным элементом её левого поддерева.
- `SEARCH n` — вывести `YES`, если число есть в дереве, иначе `NO`.
- `PRINTTREE` — вывести дерево в порядке симметричного обхода. Перед значением вершины выводится столько точек, какова её глубина (корень имеет глубину 0).

### Входные данные

В каждой строке записан один запрос: `ADD n`, `DELETE n`, `SEARCH n` или `PRINTTREE`.

Общее количество запросов не превышает `1000`, среди них не более `20` запросов `PRINTTREE`. Запрос `PRINTTREE` выполняется только для непустого дерева.

### Выходные данные

Для каждого запроса выведите соответствующий ответ. При `PRINTTREE` выведите все вершины дерева по описанному правилу.

**Решение:** [a.py](./a.py)

## b. Количество уровней дерева

Выведите количество уровней построенного дерева.

### Пример

**Входные данные**

```text

```

**Выходные данные**

```text
4
```

## k. Следующий

Реализуйте множество целых чисел, поддерживающее операции:

- `+ x` — добавить число `x` в множество; если оно уже существует, множество не изменяется;
- `? x` — найти минимальный элемент множества, который не меньше `x`. Если такого элемента нет, вывести `-1`.

Если операция добавления идёт в начале или сразу после другой операции добавления, в множество добавляется число `x`. Если она идёт сразу после запроса `?`, результатом которого было `y`, добавляется число `(x + y) mod 10⁹`.

### Входные данные

В первой строке задано количество операций `n`. В следующих `n` строках записаны операции вида `+ x` или `? x`. Изначально множество пусто.

### Выходные данные

Для каждого запроса `? x` выведите в отдельной строке найденное число или `-1`.

### Пример

**Входные данные**

```text
6
+ 1
+ 3
+ 3
? 2
+ 1
? 4
```

**Выходные данные**

```text
3
4
```

**Решение:** [k.py](./k.py)
